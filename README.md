# Subnet Calculator Pro

A Python-based networking project that calculates IPv4 subnet information using CIDR notation.

## Features

- Network Address calculation
- Subnet Mask calculation
- Broadcast Address calculation
- Total IP Addresses
- First and Last Usable IP
- Usable Host calculation
- Invalid IP and CIDR validation
- Support for /31 and /32
- Menu-driven terminal interface

## Technologies Used

- Python
- IPv4 Networking
- VS Code

## How to Run

Run this command in the terminal:

```bash
python subnet_calculator.py
```

Enter an IP address with CIDR notation, for example:

```text
192.168.1.64/26
```

## Example Output

- Network Address: 192.168.1.64
- Subnet Mask: 255.255.255.192
- Broadcast Address: 192.168.1.127
- Total IPs: 64
- Usable Hosts: 62
